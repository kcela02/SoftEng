5.1 CONCLUSIONS
================================================================================

This section presents conclusions based on the objectives of the study.


5.1.1 Summary of Findings
--------------------------------------------------------------------------------

Based on the results presented in Chapter IV, the following conclusions 
are drawn:

1. Regarding Forecasting

   The Predictive Sales & Restocking Dashboard successfully analyzed 
   historical sales data and generated forecasts using ARIMA and Linear 
   Regression models. The system was able to generate accurate multi-horizon 
   predictions (1-day, 7-day, and 30-day) for each product. ARIMA automatically 
   selected the best-fit model order using the Akaike Information Criterion (AIC), 
   ensuring reliable forecast outputs. The system achieved a forecast pass rate 
   of 100% during testing when sufficient historical data was available.

2. Regarding Inventory Management

   The system provides real-time inventory tracking and automatic restock 
   alerts when stock falls below the reorder level. This helps VAPE CRIB 
   proactively manage stock levels by classifying alert severity as CRITICAL, 
   HIGH, or MEDIUM based on forecast horizons, and by recommending order 
   quantities with a built-in 20% safety margin to prevent stockouts.

3. Regarding User Acceptance

   User acceptance testing showed that the system is highly regarded by end 
   users, receiving an average satisfaction rating of 4.8 out of 5 across 
   all evaluation criteria. The dashboard interface was found to be intuitive, 
   visually appealing, and easy to navigate by both the VAPE CRIB owner and staff.

4. Regarding System Functionality

   All core features including CSV upload, data processing, forecasting, 
   and alert generation were successfully implemented and tested. The 
   system achieved a 100% pass rate across all 27 test cases, spanning 
   authentication, CSV upload, data processing, forecasting, inventory 
   management, restock alerts, and dashboard functionality.
